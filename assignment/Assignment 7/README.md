# Assignment 7: Naïve Bayes

The supplied brief is [AML Assignment 07 NB 2026.pdf](<AML Assignment 07 NB 2026.pdf>).
It asks students to use recorded PyNBSimbot data, discretize the sensor inputs,
build Naïve Bayes conditional probability tables for the four movement actions,
and use the model to control a second robot. The instructor starter is in the
separate fork on the
[`assignment-7-nb` branch](https://github.com/Palapluem/cpe-aml/tree/assignment-7-nb/asm-7_PyNBSimbot).
The starter folder contains the simulator and history-collection examples; it
does not yet contain an implemented Naïve Bayes controller.

Lecture 7 files are in
[`Lecture 7: Naïve Bayes Classifier`](<../../lecture/Lecture 7_Naïve Bayes Classifier/>).
The brief names `history_all.csv` from a previous assignment as training input;
that data file is not included with the starter.

## Numbering in the supplied brief

The filename says Assignment 07, but the document cover says “AML-Assignment#8
- NB.” The original file is kept unchanged. Confirm the intended assignment
number with the instructor before using it in a submission label.
